# Creator 界面规范

Creator 使用窄竖窗，标题栏与内容区共用底色。系统窗口按钮保留各平台的位置，标题栏的空白处可以拖动。界面参考 Typora 的一体化窗口与克制排版。 [Typora 窗口设计](https://support.typora.io/What%27s-New-1.12/)

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 窗口背景 | `#FAF9F6` | `#1B1C1F` |
| 输入框 | `#EFEEEA` | `#25262A` |
| 悬停 | `#EAE9E5` | `#2A2C31` |
| 主操作 | `#3D54AE` | `#B3C2FF` |
| 标题文字 | `#272727` | `#EEEDEF` |
| 次要文字 | `#626168` | `#ABA9B2` |

管理器默认随系统切换浅色和深色，也可以在设置里固定外观。管理器、安装包和官网共用带窗口的蓝色盒子图标。

## 布局与交互

- 默认窗口为 448 × 640，最小 388 × 502。原生窗口按钮独占顶部拖拽区域。Creator 图标和名称放在下一行，与正文保持 17 像素的左侧留白，页面切换位于品牌行右侧。
- 默认启动到创建页，可直接粘贴网址。设置从应用库启动时，读取完成后聚焦搜索框或「创建第一个应用」，读取失败则聚焦「重试」。读取期间可继续使用顶部的页签和菜单，已有焦点会保留。
- 从系统入口重新打开已运行的 Creator 时，恢复原窗口并保留草稿。
- 品牌行的 Creator 标识带下拉箭头。点开可进入「设置…」和「关于 Creator」，系统应用菜单也提供同一入口。macOS 按 `⌘,` 打开设置，Windows 和 Linux 按 `Ctrl+,`。外观、启动页和新应用默认尺寸分组显示，主窗口保留打开的表单。保存期间在主按钮的位置显示「正在保存…」，失败时保留输入供重试。保存成功后应用外观，启动页在下次打开 Creator 时生效。按 `Esc` 或点「取消」可放弃更改。「关于」显示应用图标和版本，支持复制版本号和查看可选取的许可证原文。
- 创建页顶部合并网址输入和站点搜索，下方用分类筛选。默认五列显示 29 个推荐应用，第一行可见 DeepSeek 和小红书。卡片显示 46 像素图标和站点名，指针停在名称上可查看完整名称和域名。别名或用途筛到一个站点时，回车直接打开创建表单。
- 创建页和应用库优先显示含有连续搜索文字的结果。没有连续匹配时，每个搜索词可以在名称、网址或推荐站点的用途里分别匹配。推荐搜索遵循当前分类，完整网址沿用既有预览和创建流程。
- 拖入单个网页链接时，切到创建页并聚焦网址框。按回车从预览打开创建表单。
- 空应用库的「创建第一个应用」直接聚焦创建页的输入框，选中已有的搜索词以便粘贴替换。输入为空时，「添加」打开空白表单。输入网址或搜索词后，搜索框尾部显示更窄的清除按钮。创建页和应用库均可点击清除，或用 `Tab` 和回车操作，随后焦点回到搜索框。编辑或清空输入后从首条结果开始，创建页保留所选分类。
- 按 `↓` 从搜索框移到网址卡片或首个推荐结果。方向键在网格中按行列移动，超出可见区域时自动滚动。回车打开当前卡片，取消表单后回到原卡片和滚动位置，`Esc` 从结果回到搜索框。多个结果匹配时，搜索框内的回车保留输入焦点。分类和推荐网格各占一个 `Tab` 停靠点。
- 有效网址在输入框下方显示一张 52 像素高的卡片，包含站点名称、实际网址和 32 像素图标。长网址在卡片内保留首尾。推荐列表仍可用。已知站点直接显示内置图标，其他站点先显示临时图标。手动输入时，卡片在后台读取本机缓存。粘贴完整网址时，卡片会继续查找尚无缓存的网站图标。点击卡片或按回车打开创建表单，沿用完整网址和正在进行的查找。取消表单回到原网址后，卡片继续接收站点名称和图标。查找期间可以继续编辑和创建。
- 表单先展示图标、网址和名称。读取已安装图标时先显示临时图标，读取完成后替换。点击图标打开系统图片选择器。自定义照片按图片记录的方向显示，保留比例和透明边距。选择图片后，表单显示「恢复网站图标」。底部左侧的「窗口尺寸」展开宽高并聚焦宽度，收起后保留尺寸草稿。主操作位于同一行右侧，保存期间显示状态。
- 编辑已安装应用时用「首页网址」标识网站的起始页。校验错误在字段或宽高分组下只显示一条，并聚焦对应字段。宽度或高度超出范围时，提示会列出所属尺寸的有效范围。提交时自动展开已收起的尺寸，修正后可从输入框按回车提交。换图标的提示在指针悬停时显示，键盘操作时用焦点环和无障碍标签标识该按钮。
- 任意网址的创建表单把站点声明的名称显示为输入提示。从网站清单取图时，清单中的应用名或简称也可以作为建议。直接输入推荐站点的网址也会显示预设名称。手选本地图标后仍可使用当前网站的名称建议。留空使用该名称，图标还在加载也可以提交。名称和图标沿用本地缓存。切换到新的网址时重新匹配名称，手动输入和已安装应用的名称由用户编辑。
- 操作反馈只显示最新一条。打开表单或移除确认时收起已有的提示，为当前操作留出空间。
- 应用库使用通栏搜索和 44 像素高的列表，最小窗口可显示七条完整记录。卡片第二行显示域名、端口和路径，相同简写对应不同首页时显示完整网址，长地址保留首尾。可见行在后台读取已安装的图标。启动或修复中的条目完成后补齐图标，其余图标继续加载。新建或重复提交后，列表滚动到对应应用并显示键盘焦点，按回车即可打开。长列表把定位的条目放在视口中部，让底部提示留出操作空间。编辑、复制完整网址、显示文件和移除集中在同一个菜单按钮。复制的网址保留查询参数和片段。等待启动时，当前行显示「正在打开…」，其他应用仍可打开和编辑。历史上同名且域名相同的条目以序号区分。
- 应用库搜索有唯一匹配时，按回车可打开。按 `↓` 进入第一条可用结果，`↑` 和 `↓` 按列表顺序移动并自动滚动。已聚焦的条目正在打开时仍可用方向键离开，重复按回车只发起一次打开，后续导航跳过正在打开或移除的条目。按 `Esc` 或在第一条可用结果按 `↑` 回到搜索框，保留筛选内容。多个结果匹配时，从搜索框按回车保留输入焦点。
- 编辑保存后，焦点回到对应应用，列表按需滚动。应用仍匹配时保留搜索。改名或改网址后原搜索会隐藏该应用时，清空搜索以显示保存结果。保存失败时保留草稿和搜索。
- 应用库和编辑表单保留正在显示的图标。离开视口后，按约 12 MiB 的像素预算缓存最近显示过的图标，重新显示时可从安装文件读取。修改首页网址的 `#` 片段时沿用相同的图标或正在进行的查找，应用保存完整的新网址。
- 图标查找期间，为同一网址创建的多个应用共用这次查找。应用分别保存名称和完整首页，图标返回后依次更新系统入口。移除其中一个应用时，其余应用仍可收到图标。
- 确认移除后关闭确认框，在对应行显示「正在移除…」并暂停该行的操作。失败时恢复行内地址和操作，提示重试。
- 独立应用的主窗口隐藏系统标题和分隔线。网页在系统按钮及拖动区下方铺满其余空间。macOS 由系统 WebKit 提供窗口底色，Windows 和 Linux 使用 MyGo 原生拖动区。
- macOS 独立应用重开时恢复上次的窗口位置和尺寸。通过 Creator 调整尺寸后，独立应用在原来的屏幕应用新尺寸，显示器断开时回到主屏。
- 独立应用在系统「显示」菜单中提供后退、前进、回到首页、重新载入和网页缩放。网页在窗口中铺满内容区。Windows 和 Linux 默认收起菜单，按 Alt 或 F10 可显示。网页获得焦点时也可用快捷键。保存首页时保持当前网页，触发「回到首页」时在主窗口加载最近保存的完整网址。已在首页时保留编辑中的网页。缩放只改变网页布局，主窗口的尺寸和位置照常保留。
- 「复制网页链接」和「在浏览器中打开」位于「显示」菜单。两项操作使用当前网页的完整网址，连接失败时使用出错的网址。macOS 上菜单跟随当前的网页窗口。
- 首次载入超过约 200 毫秒时，在标题栏右侧显示「正在载入…」，避开系统按钮并保持网页区域大小。提示淡入耗时 120 毫秒，开启减少动态效果时直接显示。载入完成或失败时清除提示。连接失败时，页面区域居中显示站点域名和「重新载入」。重试期间按钮显示载入状态，成功后在原窗口显示网站。
- 系统网页组件无法加载时，原生应用窗口沿用居中的标题、简短提示和主操作。主按钮为「在浏览器中打开」，聚焦后可直接按回车。用户触发操作后才打开默认浏览器。
- macOS 下载使用系统保存面板。下载失败时，原窗口显示文件名和处理方式，关闭提示后可继续使用网站。
- Linux 下载失败时在发起下载的窗口提示。如果导出子窗口已关闭，提示会显示在仍打开的主窗口。
- 悬停过渡 120 毫秒，切页和展开窗口尺寸 140 毫秒。弹窗与遮罩一起淡入约 155 毫秒，淡出约 100 毫秒。关闭时焦点立即回到原入口，过渡跟随系统的减少动态效果设置。

主题和动效由统一的 Go 配置提供。截图与操作回归使用 MyGo 测试工具。 [主题代码](../cmd/creator/theme.go) · [界面回归](../cmd/creator/desktop_test.go)

## 官网与品牌

官网沿用 Creator 的蓝色窗口图标、字标和主题色，随系统切换浅色与深色。首屏把真实的创建页和独立运行窗口放在一起，让用户看到创建结果。桌面 macOS 的主按钮指向通用版，Windows 和 Linux 的主按钮定位到对应版本列表。手机、无法识别系统或缺少当前平台安装包时，主按钮指向全部下载。

参考流畅阅读官网的内容顺序，先给安装入口和实际效果，下方提供上手指南。指南按选择站点、确认创建和打开应用展开，每一步对应一张实际界面截图。切换截图只在操作后播放短过渡，跟随系统的减少动态效果设置。 [流畅阅读官网](https://read.thinkstu.com/)
