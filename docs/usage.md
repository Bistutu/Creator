# Creator 使用指南

Creator 把常用网站变成独立的桌面应用。打开创建页即可粘贴网址，也可以拖入浏览器链接或选择推荐站点。点「创建应用」后，在应用库按回车即可打开新应用。网站使用系统 WebView，管理器用 MyGo 原生组件编写。

- 拖入或粘贴完整网址后，预览卡会在后台查找网站图标。已有缓存时直接使用。预览卡、创建表单和同一网址创建的应用共用正在进行的查找。取消表单回到原网址时，卡片会继续接收图标。查找期间可以立即创建、改名或调整尺寸，找到后会自动更新各个应用的系统图标。DeepSeek、小红书等推荐站点自带图标，也可以按名称、别名或用途搜索。
- 网站提供应用名称后，网址卡片和表单就会显示它。网页图标响应慢时，Creator 会同时读取网站清单，尽早显示可用的名称和图标。选择本地图标后仍可使用网站名称。名称留空时使用建议名称，没有可用名称时使用域名。同一网址留空创建会定位已有应用，输入不同名称可另建应用。
- 粘贴省略协议的网址时，Creator 补上 `https://`，保留完整路径、查询参数和片段。参数或片段中也可以包含其他网址。
- 搜索先匹配连续文字，再查找同时包含各搜索词的条目。创建页可以搜「小红书 攻略」，应用库可以组合应用名和域名。更改搜索后列表回到首条。在创建页按 `↓` 进入网址卡片或推荐结果，用方向键选择并按回车打开。取消创建会回到刚选中的卡片，按 `Esc` 可回到搜索框继续输入。
- 点击创建或编辑窗口中的图标，可以选择本地图片。JPEG、PNG 和 WebP 会按图片记录的方向显示。Creator 保存一份图标副本，并将它用于系统入口。编辑时也可以恢复网站图标。
- 创建时使用随软件提供的启动器。用户无需安装 Go、下载编译依赖或等待编译。一个应用正在打包时，仍可创建、打开或保存其他应用。
- 点击窗口左上的 Creator 标识可打开「设置…」或「关于 Creator」。macOS 也可以按 `⌘,` 打开设置，Windows 和 Linux 使用 `Ctrl+,`。设置包括外观、启动页和新应用的默认窗口尺寸。按 `Esc` 或点「取消」可放弃编辑。「关于 Creator」支持复制版本号和查看完整的 MIT 许可证。
- 窗口尺寸填错时，创建、编辑和设置窗口会聚焦对应的宽度或高度。窗口尺寸已收起时会自动展开，修正后按回车即可提交。
- 从系统入口再次打开正在运行的 Creator，会回到原窗口并保留未提交的草稿。
- 应用库支持搜索、编辑、打开、复制完整网址、在文件管理器中显示和移除。卡片平时显示域名、端口和路径，简写相同但首页不同的卡片会显示完整网址。搜索只有一个匹配时，按回车可直接打开。也可用 `↓` 从搜索框进入结果，再用方向键选择，按 `Esc` 返回搜索框。创建或保存后会定位到对应应用。编辑后的应用仍匹配搜索时会保留搜索。重复提交同名同网址时会定位到已有应用。改用不同名称，可以为同一网站保留独立会话。
- 移除应用时，该行显示「正在移除…」，仍可操作其他应用。系统入口或应用记录暂时无法移除时，原应用可继续打开，也可以重新尝试移除。
- 应用库和编辑窗口优先显示独立应用里的图标，网站图标缓存清空后也能显示。若上次找到图标后还没来得及更新独立应用，重开应用库会用缓存补齐。改名称、窗口尺寸或首页网址的 `#` 片段时沿用已安装的图标。设置没有修改时，保存直接返回应用库。
- 独立应用的主窗口采用一体式设计，系统窗口按钮和拖动区位于网页上方。保存窗口尺寸后，重新打开独立应用即可使用新尺寸。在支持窗口定位的桌面环境中，应用会在原位置打开。
- Windows 和 Linux 上，沿用名称和图标时，Creator 直接更新首页和尺寸配置。正在使用的窗口和网页会话会继续运行。
- 在 macOS 12.3 及更新版本和 Linux 上，网站的全屏按钮可以让播放器铺满屏幕。按 Esc 可以回到原窗口，网页状态会保留。
- 再次打开已运行的应用会回到原窗口。为同一个网址另建的应用可以同时运行，并各自保留登录状态。
- macOS 上可以用 `⌘ M` 最小化独立应用窗口。再次打开应用时会恢复原窗口，保留网页里的未保存内容。
- 独立应用首次打开网页较慢时，标题栏会显示「正在载入…」。连接失败时，原窗口会显示站点和「重新载入」。重试会打开出错的网址，并继续使用当前的网站会话。
- Windows 和 Linux 检测到系统网页组件缺失时，独立应用会在原生窗口提示检查相应组件。点击「在浏览器中打开」可以把完整首页网址交给系统默认浏览器。恢复网页组件后，从原入口重新打开即可继续使用已保存的会话。
- 在 macOS 和 Linux 上，网页渲染进程意外停止时也可以在原窗口重新载入，恢复当前网址和已保存的会话。
- 在 macOS 和 Linux 上，网页使用麦克风或摄像头时，独立应用会显示相应的权限提示。
- macOS 独立应用用系统面板选择上传文件、文件夹和下载位置，支持保存网页直接生成的 CSV 等文件，也支持网页发起的提示、确认和文本输入。
- macOS 下载完毕后才保存到选定位置。确认替换同名文件后，原文件会保留至新文件完整收到。下载中断或目标文件在此期间被修改时，原窗口会提示原因。
- Windows 和 Linux 上，独立应用的文件下载完成后会保存到系统下载目录。同名文件会自动编号。Linux 上主窗口仍打开时，关掉导出子窗口后下载会继续，传输失败会在仍打开的窗口提示。

独立应用的「显示」菜单提供「回到首页」。在 Creator 修改首页后，当前网页可以继续使用。触发「回到首页」会在原窗口打开最近保存的完整网址，保留路径、查询参数、片段和网站会话。已在首页时再次执行会保留当前网页状态。

在独立应用主窗口中，也可以通过「显示」菜单复制网页链接，或用系统默认浏览器打开。网页载入失败时，两项操作使用出错的网址。

独立应用支持以下窗口快捷键。

| 操作 | macOS | Windows 和 Linux |
| --- | --- | --- |
| 后退 | `⌘ [` | `Alt` + `←` |
| 前进 | `⌘ ]` | `Alt` + `→` |
| 回到首页 | `⌘ ⇧ H` | `Alt` + `Home` |
| 重新载入 | `⌘ R` | `Ctrl` + `R` |
| 放大网页 | `⌘ =` | `Ctrl` + `=` |
| 缩小网页 | `⌘ -` | `Ctrl` + `-` |
| 实际大小 | `⌘ 0` | `Ctrl` + `0` |
| 关闭窗口 | `⌘ W` 或 `⌘ X` | `Ctrl` + `W` |

主窗口按应用记住网页缩放比例，关闭后从系统入口重新打开也会恢复。

macOS 关闭最后一个窗口后，应用继续运行。从程序坞或 Creator 重新打开会恢复原网页和未保存的输入。按 `⌘ Q` 退出应用，剪切可通过「编辑 → 剪切」完成。

## 平台

| 系统 | 创建结果 | 网站运行环境 |
| --- | --- | --- |
| macOS | 用户「应用程序」下的 Creator 文件夹 | 系统 WebKit |
| Windows | 开始菜单里的 Creator 文件夹 | Microsoft Edge WebView2 Runtime |
| Linux | 应用菜单里的独立应用 | GTK 3 与 WebKitGTK |

创建好的入口会随应用改名、更新图标或移除。macOS 上已有的应用沿用原安装目录，新创建的应用放在 `~/Applications/Creator`。Windows 开始菜单入口使用 Creator 文件夹。本机配置沿用用户数据目录下的 `WebCrate` 子目录，应用保留原有标识和会话。

在 macOS 上，独立应用开着时也可以在 Creator 里改名、更换图标或调整尺寸。打开入口会回到正在使用的窗口，退出后重新打开应用会使用新尺寸和已保存的会话。

Linux 为每个应用保留独立的窗口标识。应用改名后仍与原系统入口关联，同名应用也可以各自显示在任务栏里。

Windows 为每个网站应用分配任务栏标识。开始菜单入口和应用窗口共用该标识，改名时沿用。同名网站应用可以独立分组。 [Windows 任务栏应用标识](https://learn.microsoft.com/zh-cn/windows/win32/shell/appids)

Creator 在整理应用入口或从应用库打开应用时检查启动器版本。更新后重新打开独立应用即可使用新版本，已保存的配置、图标和会话会沿用。macOS 会在原位置更新启动器，正在运行的窗口可以继续使用。Windows 和 Linux 版用随安装包提供的校验值快速检查版本，复制或共享启动器时会校验内容。在支持硬链接的磁盘上，同版本应用共用启动器数据。

打开 Creator 或从应用库启动时，如果独立应用的启动文件丢失或不完整，或者网站配置损坏，Creator 会根据已保存的设置修复应用。修复沿用原系统入口、网站会话和现存图标。Windows 和 Linux 在修复一个应用的启动器时，其他启动器完整的应用仍可打开。

独立应用从系统入口启动时，如果自己的配置丢失或无法读取，会按应用标识读取 Creator 应用库中上次保存的设置，接续原来的首页、窗口尺寸和会话。若 macOS 在启动前拒绝损坏的签名包，可从 Creator 应用库修复。 [Apple 应用签名资源说明](https://developer.apple.com/documentation/Technotes/tn3126-inside-code-signing-hashes)

macOS 会复用仍有效的系统登记。创建、改名、更换图标和重建应用包后会刷新各自的登记。 [Apple Launch Services](https://developer.apple.com/documentation/coreservices/1446350-lsregisterurl)

Creator 意外退出后，重开会在后台清理中断的打包目录，补做已提交移除的文件清理。移除尚未提交时，会恢复原安装。

## 安装

在 macOS 打开通用版 DMG，将 Creator 拖入「应用程序」。在 Creator 中完成创建后，可从应用库或用户「应用程序」的 Creator 文件夹打开独立应用。Windows 运行对应架构的安装程序，完成后从开始菜单打开 Creator。Debian 和 Ubuntu 可安装对应架构的 DEB。

macOS 安装包使用临时签名，首次打开时可能需要在「隐私与安全性」确认。 [Apple 使用指南](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unidentified-developer-mh40616/mac)

## 开发与构建

源码开发使用 Go 1.27.3 或更新版本。构建 macOS 启动器需要 Xcode 命令行工具。Windows 和 Linux 的启动器在打包 Creator 时由 Go 预编译。

```sh
go run ./cmd/package -prepare
go tool mygo dev
```

构建当前平台的发布包。

```sh
go run ./cmd/package
```

例如在 Mac 上构建本机 `.app`，并跳过 DMG。

```sh
go run ./cmd/package -- -skip-dmg
```

开发资料包括 [测试指南](testing.md) 和 [Creator 界面规范](ui-style.md)。

官网下载页使用同一套品牌色和实际桌面截图。打包和预览步骤见 [官网说明](../website/README.md)。

## 许可与图标

Creator 独立实现并采用 MIT 许可，网站打包功能受 Pake 启发。 [项目许可](../LICENSE) · [Pake](https://github.com/tw93/Pake)

Creator 图标由 `internal/icons` 生成。推荐目录中的各标志用于识别站点，归各自权利方所有。DeepSeek 图标来自 Lobe Icons，源文件存放在 `internal/catalog/marks`。 [Simple Icons 15.21.0](https://www.npmjs.com/package/simple-icons/v/15.21.0) · [Lobe Icons 静态图标 1.104.0](https://www.npmjs.com/package/@lobehub/icons-static-svg/v/1.104.0) · [Lobe Icons MIT 许可](../resources/Lobe-Icons-LICENSE.txt)

维护推荐图标时，在项目根目录运行 `go run ./cmd/assets -simple-icons /path/to/simple-icons-15.21.0.tgz`。生成器先核对输入存档的 SHA-256，再写入 `internal/catalog/tiles` 的内置资源和品牌图标。
