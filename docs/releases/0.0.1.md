## English

Creator 0.0.1 is the first public release. Give any regular web address its own desktop window, icon, and system launcher.

### Create and manage apps

- Paste or drag a URL, or choose a preset such as DeepSeek, Xiaohongshu, GitHub, or Notion. Edit the name, icon, and initial window size before creating.
- Open, edit, or remove apps from the library. Created apps can launch from the system menu with their own website sessions. The View menu includes Home, Reload, Zoom, and Copy Page Link.
- Open Settings with `⌘,` on macOS or `Ctrl+,` on Windows and Linux. Choose the appearance, startup page, or default size.

## 中文

Creator 0.0.1 是首个公开版本。常用网站可以拥有自己的桌面窗口、图标和系统应用入口。

### 创建与管理

- 粘贴或拖入网址，或从 DeepSeek、小红书、GitHub、Notion 等推荐站点开始。创建前可调整名称、图标和初始窗口尺寸。
- 在应用库打开、编辑或移除应用。已创建的应用可以从系统菜单启动，并各自保留网站会话。「显示」菜单提供回到首页、重新载入、缩放和复制网页链接。
- macOS 按 `⌘,` 打开设置，Windows 和 Linux 按 `Ctrl+,`。设置支持外观、启动页和新应用默认尺寸。
